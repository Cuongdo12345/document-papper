Handoff phải thể hiện:

- Current Task

- Objective
- Completed
- Current Understanding
- Files Analyzed
- Files Modified
- Important Functions
- API Impact
- Database Impact
- Security Impact
- Tests Executed
- Test Results
- Known Problems
- Unresolved Questions
- Exact Next Action

`Exact Next Action` phải là hành động cụ thể.

Ví dụ:

```text

validation for departmentId.
```

