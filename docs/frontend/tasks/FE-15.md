## 3.1. Bug phát hiện SAU khi người dùng thử với file thật (2026-09-10)

- **Báo cáo**: import Asset qua Excel, bấm "Xem trước" → lỗi 400 "Không tìm thấy sheet" dù file hợp lệ, có dữ liệu (screenshot Network tab: `assets.api.ts:117`, `import?dryRun=true`).
- **Root cause CONFIRMED (HIGH)** — File: `backend/src/services/assets/assetDevice/assetExcel.service.ts`, function `importAssetsExcel()` (và 2 hàm cùng pattern: `importDocumentsExcel()`, `syncDepartmentFromExcel()` ở `backend/src/services/excel/excel.service.ts`). Cả 3 đều gọi `workbook.getWorksheet(1)`. Đọc thẳng source `exceljs@4.4.0` (`node_modules/exceljs/lib/doc/workbook.js:106-117`): khi tham số là **số**, hàm tra thẳng vào mảng nội bộ theo **ID sheet lưu TRONG file .xlsx** (`this._worksheets[id]`), KHÔNG theo vị trí tab hiển thị. File `.xlsx` do Excel/LibreOffice/WPS lưu qua nhiều lần xoá/tạo lại sheet thường có ID sheet đầu tiên ≠ 1 → `getWorksheet(1)` trả `undefined` dù sheet đầu tiên (theo tab) hoàn toàn hợp lệ, có dữ liệu. File test của user ("BVHC tháng 6.xlsx") rơi đúng trường hợp này.
  - Test hiện có (`excel.service.test.ts`) KHÔNG bắt được bug vì tự tạo workbook bằng `addWorksheet()` trong cùng session — luôn được gán `id=1`, không tái hiện file thật đã qua chỉnh sửa nhiều lần.
- **Fix**: đổi cả 3 chỗ sang `workbook.worksheets[0]` — getter này trả về `Worksheet[]` ĐÃ SẮP THEO VỊ TRÍ TAB thật (`orderNo`), đúng ngữ nghĩa "sheet đầu tiên trong file" (typed rõ trong `exceljs/index.d.ts:1751`: "return a clone of worksheets in order").
- Tại sao sửa cả 3 thay vì chỉ Asset (đúng phạm vi báo cáo): cùng root cause, cùng pattern copy-paste, cùng file input do người dùng thật tải lên → để lại 2 chỗ kia sẽ vỡ đúng cách tương tự khi người dùng thử Document import/Department sync với file thật. Không phải mở rộng scope — là cùng 1 bug class đã có evidence trực tiếp.
- Verify: `npx tsc --noEmit` — PASS. `npx jest` — **97/97 PASS** (0 regression, bug này không có test nào phủ nên không thể viết test riêng trong phạm vi task mà không mở rộng đáng kể — ghi nhận `Known Issues`).
