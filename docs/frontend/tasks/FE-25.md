## 1. Yêu cầu

Mở rộng `SystemDesignDetailDrawer` hiện có (không thêm trang mới): khi click Module, hiện thêm phần "Tài
liệu liên quan" — mô tả + tính năng + danh sách link GitHub, mở tab mới khi click.

## 2. Thay đổi

- `types/systemDesign.types.ts` — `SystemDesignModule` thêm `description?`, `features?`, `relatedDocs:
  SystemDesignRelatedDoc[]` (interface mới `{path, url}`) — khớp ĐÚNG response mới của `DEV-074`, không suy
  đoán field.
- `components/SystemDesignDetailDrawer.tsx` — `SystemDesignDrawerState` thêm biến thể `{kind: "module";
  module: SystemDesignModule}`. Render thêm 1 khối mới (chỉ khi `kind === "module"`): danh sách model trong
  module (tái dùng style tag đã có ở phần "model" cũ), mô tả (nếu có), tính năng chính dạng bullet list HTML
  thuần `<ul className="list-disc">` (KHÔNG markdown renderer — đúng ràng buộc, feature vốn đã là mảng
  string từ `moduleDescriptions.ts`, không phải nội dung markdown cần parse), và "Tài liệu liên quan" — mỗi
  item là `<a href={doc.url} target="_blank" rel="noreferrer">{doc.path}</a>` (mở tab mới, hiển thị path
  repo-relative dễ đọc thay vì URL đầy đủ). Trường hợp rỗng: hiện dòng "Chưa có task doc nào nhắc tới module
  này" thay vì để trống im lặng.
- `components/SystemDesignCanvas.tsx` — thêm prop `onModuleClick: (moduleName: string) => void`. Trong
  `handleNodeClick`, khi click node Module: giữ nguyên `fitView` đã có (FE-24), gọi THÊM `onModuleClick` (2
  hành động cùng lúc — click Module vừa zoom vừa mở Drawer, không thay thế hành vi cũ).
- `pages/SystemDesignPage.tsx` — thêm `handleModuleClick(moduleName)`: tìm module tương ứng trong
  `query.data.modules` (đã có sẵn field mới từ API, không cần fetch thêm), set `drawerState = {kind:
  "module", module}`. Truyền `onModuleClick={handleModuleClick}` xuống `SystemDesignCanvas`.

## 3. Vì sao không cần fetch thêm dữ liệu

`query.data.modules` (từ `useSystemDesign()`, đã fetch sẵn khi trang load) đã có đủ `description`/
`features`/`relatedDocs` sau khi backend `DEV-074` trả về — click Module chỉ cần tra cứu trong state đã có,
giống cách `handleModelClick`/`handleEdgeClick` đang làm (tái dùng đúng pattern, không tạo thêm request
riêng cho Drawer).
