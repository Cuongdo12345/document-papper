# FE-32 — Màu icon theo module trên Sidebar

**Ngày:** 2026-09-25
**Trạng thái:** DONE. User gửi ảnh Sidebar (toàn icon xám đơn sắc), yêu cầu "cập nhật màu cho các icon
của module trên thanh sidebar".

## 1. Hỏi trước khi làm (2 câu hỏi, AskUserQuestion)

- **Phạm vi tô màu**: theo TỪNG mục riêng (~15 icon) hay theo NHÓM (~5 nhóm: Tổng quan/Tài liệu/Tài sản
  & Vật tư/Nhà cung cấp/Quản trị hệ thống) — user chọn **theo NHÓM**.
- **Nguồn màu**: dùng lại token ngữ nghĩa có sẵn (primary/success/warning/info/destructive) hay tạo bảng
  màu module MỚI riêng — user chọn **tạo bảng màu MỚI**.

## 2. Vì sao KHÔNG tự chọn màu bằng mắt — dùng skill `dataviz`

5 màu cần phân biệt rõ, đúng cả light/dark, không được đụng lại 3 token trạng thái đã có nghĩa cố định
(`--success`/`--warning`/`--destructive` — dataviz skill: "status colors are reserved, never reused for
series identity"). Skill `dataviz` cung cấp đúng loại kiểm tra cần cho việc này (dù đây là icon điều
hướng, không phải chart, nhưng cùng bài toán "categorical color" — nhiều màu định danh cạnh nhau, phải
qua được kiểm tra mù màu/contrast) — dùng `references/color-formula.md` (6 check) + chạy thật
`scripts/validate_palette.js`, KHÔNG suy luận cảm tính.

### Quy trình chọn màu

1. **Vùng hue an toàn**: loại các hue trùng 3 token trạng thái (đỏ ~H25, cam/vàng ~H75, xanh lá ~H155,
   mỗi bên ±20°) — thử 5 hue trong dải xanh dương→tím→hồng (175°–345°) trước, **THẤT BẠI**: quá gần nhau
   (CVD ΔE chỉ 2.0, dưới ngưỡng bắt buộc 8.0) vì dải này quá hẹp cho 5 màu phân biệt được.
2. Chuyển sang dùng **5 slot ĐẦU** của bảng categorical mặc định đã validate sẵn của skill (`palette.md`)
   — blue/orange/aqua/yellow/magenta, thứ tự này đã chứng minh pairwise AN TOÀN (dùng đúng nguyên bộ
   liền kề, không tự phối lại) — hợp lý vì icon sidebar LUÔN có label chữ đi kèm (trừ chế độ thu gọn), tức
   luôn có "secondary encoding" — dùng chuẩn "adjacent pairs" (không phải "all pairs" khắt khe hơn dành
   cho biểu đồ scatter).
3. Chạy `validate_palette.js` với ĐÚNG surface Sidebar của project (`--sidebar` token, quy đổi OKLCH →
   hex: light `#fbfcfd`, dark `#090e14`, KHÔNG dùng surface mặc định của skill) — **PASS** cả 5 check ở
   cả 2 mode, NGOẠI TRỪ contrast: aqua/yellow/magenta ở light mode dưới 3:1 (2.74/2.11/2.62) trên nền
   sidebar gần trắng.
4. Hạ `L` (giữ nguyên hue/chroma) của riêng 3 màu light-mode đó tới khi đạt 3:1 — chạy lại validator: PASS
   toàn bộ 5 check cả 2 mode (CVD ΔE 9.0 protan / normal-vision ΔE 16.9 / contrast ≥3:1 khắp).

Chi tiết OKLCH cuối cùng — xem comment ở `frontend/src/index.css` (token `--module-*`).

## 3. Implementation

- `frontend/src/index.css` — 5 token mới `--module-overview/documents/assets/vendors/admin` (khai báo
  RIÊNG light `:root` + `.dark`, đăng ký `--color-module-*` ở `@theme inline` — sinh util Tailwind
  `text-module-*` tự động, đúng pattern `--color-success` đã dùng).
- `frontend/src/config/navigation.ts` — `NavItem` thêm field `moduleColor` (5 giá trị enum), gán CÙNG 1
  giá trị cho mọi item trong 1 nhóm liền kề + 1 giá trị riêng cho "Tổng quan" (item đứng riêng).
- `frontend/src/layouts/Sidebar.tsx` — icon dùng `MODULE_COLOR_CLASS` (bảng tra cứu literal, KHÔNG ghép
  chuỗi `text-module-${...}`, vì Tailwind v4 quét class TĨNH trong source — class ghép động sẽ KHÔNG được
  sinh ra trong CSS output, cùng lý do `StatusBadge`/`ASSET_STATUS_MAP` dùng bảng tra cứu). Icon đè màu cố
  định lên `currentColor` cũ (trước đây icon ăn theo màu text cha, giờ luôn giữ màu module dù active/hover
  — hover/active pill vẫn giữ nguyên hiệu ứng nền cũ, không đổi). Text label GIỮ NGUYÊN màu trung tính
  (dataviz skill: "text wears text tokens, never the series color") — CHỈ icon đổi màu, đúng đúng phạm vi
  user yêu cầu.

- **Spot-check UI thật** bằng Playwright tạm (đã xoá): 5 icon nhóm (Tổng quan/Tài liệu/Tài sản/Nhà cung

  liệu, Duyệt tài liệu) CÙNG màu; bật `.dark` → màu icon đổi sang giá trị dark riêng (khác light); chụp
  ảnh xác nhận bằng mắt: 5 màu rõ ràng, hài hoà, không neon, hover pill vẫn hoạt động bình thường, dark
  mode contrast tốt.

## 5. Ghi chú / ngoài phạm vi

- Label chữ của nhóm (vd "TÀI LIỆU" ở đầu mỗi block) và text nav item GIỮ NGUYÊN màu trung tính cũ — user
  chỉ yêu cầu đổi màu ICON.
- Ở chế độ Sidebar thu gọn (icon-only rail), không còn label chữ đi kèm — chỉ còn tooltip `title` khi
  hover + vị trí cố định để phân biệt module, ĐÚNG hành vi hiện có từ trước (FE-32 không đổi gì ở đây,
  chỉ thêm màu — màu càng hữu ích hơn trong chế độ này vì không còn chữ).
- Không tạo permission/route/API mới — thuần CSS token + 1 field khai báo dữ liệu tĩnh, không có RBAC/DB
  impact.
