`Header.tsx`.
**Bối cảnh**: `FE-29.md` Mục 2 phát hiện token CSS dark mode (`.dark { ... }` trong `index.css`, kể cả
`--success-strong` dark mới thêm) tồn tại từ FE-01 nhưng KHÔNG có cơ chế nào bật được trong app thật —

## 1. Thiết kế

- **State**: thêm `theme: "light" | "dark"` vào `stores/uiStore.ts` (store UI đã có sẵn, đã persist
  `sidebarCollapsed` qua `zustand/persist` key `dp_ui_prefs` — tái dùng đúng pattern, KHÔNG tạo store
  mới). Thêm action `toggleTheme()`. `partialize` thêm `theme` vào danh sách field persist.
- **Áp class `.dark` lên `<html>`**: hook mới `hooks/useThemeSync.ts`, gọi 1 lần ở `App.tsx` (cùng chỗ
  `useAuthBootstrap()`) — `useEffect` toggle `document.documentElement.classList` theo `theme` từ store.
- **Chống FOUC** (nháy sáng rồi mới chuyển tối khi load trang, vì React chỉ set class sau khi mount):
  thêm 1 `<script>` inline trong `frontend/index.html`, chạy TRƯỚC `main.tsx`, đọc thẳng
  `localStorage["dp_ui_prefs"]` (cùng key zustand persist dùng, cấu trúc `{state:{theme}, version}`) và
  set class `.dark` ngay nếu có — bọc `try/catch` vì `localStorage` có thể bị chặn (private mode).
- **UI toggle**: 1 nút icon đơn trong `layouts/Header.tsx` (Sun khi đang dark — bấm để về light; Moon
  khi đang light — bấm để sang dark; icon từ `lucide-react`, cùng thư viện đang dùng toàn app), đặt cạnh
  `NotificationBell` — theo đúng yêu cầu user, KHÔNG đặt trong dropdown user menu.
