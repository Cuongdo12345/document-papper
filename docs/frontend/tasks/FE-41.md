# FE-41 — Giới hạn 10 file mỗi lần tải lên (đi kèm DEV-103 / BR-15)

**Ngày:** 2026-09-30
**Trạng thái:** DONE
**Loại:** UI/UX, API CHANGE (contract)

## 1. Bối cảnh

Backend (`DEV-103.md`) giới hạn `POST /api/upload` tối đa **10 file mỗi request**. Giao diện "Tải file lên" (`FilesListPage`) cho chọn nhiều file không đếm, nên nếu không sửa, người dùng chọn 12 file sẽ phải chờ tải lên rồi mới nhận lỗi chung "Vượt quá số lượng file cho phép" (không nói con số).

## 2. Thay đổi

- `components/shared/FileUpload.tsx`: thêm prop tuỳ chọn `maxFiles`. Khi `multiple` và tổng số file (đã chọn + vừa thêm) vượt giới hạn, báo lỗi ngay `Chỉ được chọn tối đa N file mỗi lần tải lên` và **không thêm file nào** (cùng cách các lỗi validate khác của component này). Các nơi dùng khác (chọn 1 file) không truyền prop, nên không đổi hành vi.
- `features/files/pages/FilesListPage.tsx`: `MAX_FILES = 10` (khớp `MAX_FILES_PER_REQUEST` ở backend), truyền vào `FileUpload`, đổi `helperText` thành "PDF, ảnh, Word, Excel — tối đa 10 file mỗi lần, 10MB/file".
- Không đổi API client, design token, layout.
