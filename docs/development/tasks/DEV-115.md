## 1. Mục tiêu

## 2. Quyết định của user (AskUserQuestion, 2026-10-08)
Đặt đường dẫn con **gọn, phẳng** cho cả 2 module: `/categories`, `/maintenance-plans`; riêng y tế `/:assetId/profile`, `/:assetId/calibration-records[...]`, `/operator-certificates`, cảnh báo y tế tách 2: `/alerts/run` (bảo hành/bảo trì) và `/calibration-alerts/run` (hiệu chuẩn, giấy phép, chứng chỉ).

## 3. Thay đổi
- `routes/assets/assetModule.routes.ts` (mới): router factory `buildAssetModuleRouter({ assetType, permissionPrefix })`; cấu hình `IT_ASSET_MODULE`, `MEDICAL_ASSET_MODULE`. IT: 36 route, y tế: 50 route (thêm hồ sơ, hiệu chuẩn, chứng chỉ, cảnh báo hiệu chuẩn). Static path đăng ký trước `/:id`; mọi route có id đều qua chốt cô lập **sau** `authenticate` + `authorizePermission` + `validateParams` (không có quyền → 403 trước, không lộ tồn tại).
- `middlewares/assetScope.middleware.ts` (mới): `setAssetScope`, `getAssetScope(res)`, `requireAssetInScope` / `requireCategoryInScope` / `requireMaintenancePlanInScope` / `requireOperatorCertificateInScope`. Controller dùng chung với route cũ; loại truyền qua `res.locals` (route cũ không gắn → không lọc, hành vi cũ giữ nguyên).
- `services/assets/assetType.helper.ts`: thêm `assertAssetOfType`, `assertCategoryOfType`, `getBranchCategoryIds`.
- Service nhận tham số loại tuỳ chọn (không truyền = như cũ): `createAssetService`, `getAllAssetsService`, `bulkDelete/RestoreAssetService`, `findAssetByCodeService`, `exportAssetsExcelPRO`, `importAssetsExcel` (option `assetType`), `runAssetAlertsService` (+2 hàm check), `getMaintenanceCalendarService`, và với danh mục: `createAssetCategoryService` (gốc mặc định mang loại module; gửi loại khác hoặc cha khác nhánh → 400), `getAllAssetCategoriesService`, `updateAssetCategoryService` (không cho chuyển sang nhánh khác), `bulkDelete/RestoreAssetCategoryService`.
- `app.ts`: mount 2 prefix trước `/api/assets*`.
- OpenAPI: sinh 86 operation mới cho 2 prefix từ path cũ (đổi prefix, quyền; thêm 404 cho path có id), tag `IT Assets`, `Medical Assets`; 50 operation của path cũ gắn `deprecated: true`.
- `docs/frontend/API_REFERENCE.md`: ghi chú 2 prefix mới.

## 5. Test
- **E2E mới** `asset-module-routes.e2e-test.ts` (+108, e2e tổng 334). Mỗi route × mỗi module (IT 36, y tế 50, bảng viết tay): không token → 401; user không quyền → 403; user chỉ có đúng quyền của route → không bị 401/403 (route có id ngoại lai → 404 đúng thông điệp chốt cô lập); admin trên id loại khác → 404; user có đủ quyền module kia → 403.
- Kèm: duyệt toàn bộ router xác nhận mọi route có tham số id đều có chốt cô lập; OpenAPI khớp từng method+path với route cài đặt; luồng chức năng (danh mục theo nhánh, tạo sai nhánh 400, danh sách và Excel xuất chỉ đúng loại, lookup, bulk, vòng đời tạo→sửa→cấp phát→thu hồi→QR→check-in→xoá→khôi phục→xoá vĩnh viễn, nhập Excel báo lỗi dòng sai nhánh, cảnh báo, lịch bảo trì, hồ sơ y tế, chứng chỉ); lớp tương thích (`/api/assets*` thấy cả hai loại; quyền mới không mở route cũ và ngược lại); xem chéo Q-F (IT/Vật tư-TTB xem được loại kia, sửa → 403).
