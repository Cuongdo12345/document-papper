## 1. Hiện trạng (đo trên DB dev `hospital_documents`, `$indexStats` từ 12/09)

Review ghi 4 nhóm index thừa. Đối chiếu source với DB thật cho thấy 2 tầng:

| Collection | Trong schema (source) | Trong DB dev | Kết luận |
|---|---|---|---|
| `useraudits` | ĐÃ đúng (4 index: 3 kép + `{createdAt}`) | còn thừa **4 index cũ**: `user_1`, `performedBy_1`, `action_1`, và index kép 4 field `action_1_performedBy_1_user_1_createdAt_-1` | chỉ DB dev lệch; Mongoose không tự xoá index khi sửa schema |
| `apiperformances` | 3 index, trong đó `{createdAt:-1}` trùng TTL `{createdAt:1}` | có cả hai | bỏ khỏi schema + xoá DB |
| `notifications` | `recipient` khai `index: true` (đơn) + 2 index kép có tiền tố `recipient` | có cả `recipient_1` | bỏ khỏi schema + xoá DB |
| `documents` | `{referenceTo:1}` là tiền tố của `{referenceTo, category, isActive, createdAt}` | có cả hai | bỏ khỏi schema + xoá DB |

Truy vấn thật đã kiểm chứng bằng đọc code: `apiperformances` chỉ `$match` theo khoảng `createdAt` rồi `$group` (`performance.controller.ts`); notifications luôn lọc `recipient` (+ `isRead`) (`notification.service.ts`); mọi truy vấn `referenceTo` (kể cả BR-17 `{subType, isActive, referenceTo:{$in}}` và `$lookup` foreignField `referenceTo`) có `referenceTo` ở đầu.

## 3. Thay đổi

Schema:
- `notification.model.ts`: bỏ `index: true` ở `recipient`.
- `apiPerformance.model.ts`: bỏ `ApiPerformanceSchema.index({ createdAt: -1 })`.
- `document.model.ts`: bỏ `DocumentSchema.index({ referenceTo: 1 })`.
- `userAudit.model.ts`: chỉ thêm ghi chú (schema đã đúng).

Xoá index đã tồn tại trong DB:
- `src/shared/helpers/redundantIndexes.helper.ts` (mới, có test): danh sách 7 index thừa, mỗi mục kèm `coveredBy`. `dropRedundantIndexes(db, {apply})` xoá **đích danh theo tên** (không dùng `syncIndexes()` để khỏi lỡ xoá index khác), **chỉ xoá khi index thay thế đang tồn tại** (không thì `kept-no-cover`, giữ lại), collection chưa có thì `absent`, chạy lại vô hại. Mặc định chỉ xem trước.
- `scripts/migrate-drop-redundant-indexes.ts` (mỏng, theo mẫu các migration cũ; `scripts/` không nằm trong git): `npx ts-node scripts/migrate-drop-redundant-indexes.ts` (xem trước) / `... --apply` (xoá).

Không đổi: code truy vấn, API, RBAC, frontend, dữ liệu.

## 5. Test

E2E mới `__tests__/e2e/redundant-indexes.e2e-test.ts` (11 test, MongoDB in-memory thật):
- Schema hiện tại (`syncIndexes()`) không còn tạo index nào trong danh sách thừa, index thay thế đều có; tập index từng collection đúng như mong đợi.
- Script: dry-run báo `would-drop` cả 7 mà không xoá; `--apply` xoá đúng 7, giữ index hợp lệ (kể cả TTL `createdAt_1` và `documentCode_1`) và dữ liệu; chạy lại → `absent`; collection chưa tồn tại → `absent`; thiếu index thay thế → giữ lại (`kept-no-cover`) dù `apply`.
- **Truy vấn thật vẫn dùng index** (`explain`, không `COLLSCAN`, không `SORT` trong RAM): UserAudit lọc user/performedBy/action + sort `createdAt` → 3 index kép; Notification danh sách/lọc chưa đọc → index tiền tố `recipient_1_`; ApiPerformance lọc khoảng thời gian và sort giảm dần → TTL `createdAt_1`; Document 4 kiểu truy vấn `referenceTo` (đơn, `$in`, kèm `category`/`subType` + `isActive` như BR-17) → không COLLSCAN, và truy vấn `referenceTo` đơn dùng đúng index kép.
- **Đã kiểm chứng test bắt được lỗi:** tạm khôi phục index thừa vào schema thì 2 test schema fail (lần khôi phục đầu tiên tôi gõ sai vị trí chèn nên suite không biên dịch được; lần sau đã chạy được, nhưng 1 trong 3 phép chèn báo lỗi nên không rõ chính xác đã chèn lại mấy index — chỉ chứng minh được test bắt ít nhất một index thừa); đã khôi phục từ backup, `cmp` xác nhận giống hệt.
- Toàn bộ: `tsc` 0 lỗi, unit 53 suites / 562 tests, e2e 28 suites / 189 tests (+11), `npm run build` PASS. Frontend không đổi (không chạy build/Playwright).
- Lỗi vặt của chính test khi viết: `Document` yêu cầu `department`; `countDocuments` không `explain` được; lọc tên index `createdAt_-1` trùng giữa 2 collection. Không ảnh hưởng mã production.

## 7. Cần làm khi deploy production

Mongoose `autoIndex` KHÔNG xoá index cũ. Trước/khi deploy: chạy `npx ts-node scripts/migrate-drop-redundant-indexes.ts` (xem trước), kiểm tra, rồi `--apply`. Chưa chạy với production (chưa deploy). Xoá index là thao tác nhanh và không mất dữ liệu; dựng lại bằng `syncIndexes()` nếu cần hoàn tác.
