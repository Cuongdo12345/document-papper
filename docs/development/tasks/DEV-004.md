7. **Rescue 4 test mồ côi**: chuyển nguyên `dist/**/__tests__/*.test.js` (compiled) thành `.test.ts` nguồn đúng vị trí gốc (`src/{middlewares,services/auth,services/documents,services/rbac}/__tests__/`) — cần thiết để "kiểm tra test discovery/số test phát hiện" (BƯỚC 4) có ý nghĩa thực tế, không phải hành động ngoài scope (đây chính là "test quan trọng" nêu ở Objective).

## Known Failures

1 vấn đề **INFRASTRUCTURE FAILURE** gặp phải và đã tự sửa trong task này (không phải TEST FAILURE, không phải APPLICATION FAILURE):

- **Nguyên nhân**: `jest.fn()` gọi trần (không type argument) dưới `strict:true` + `@types/jest` mới suy luận kiểu `Mock<never>`, khiến `.mockResolvedValue(...)`/`.mockReturnValue(...)` bị TypeScript từ chối biên dịch (lỗi `TS2345: Argument of type '...' is not assignable to parameter of type 'never'`) — CHỈ xảy ra ở `auths.service.test.ts` (dùng nhiều chuỗi mock lồng `select().populate().populate()`), 3 file rescue còn lại KHÔNG gặp vì dùng `jest.mocked(...)` cho hàm cấp cao nhất.
- **Fix**: thêm helper `const fn = () => jest.fn() as any;` ngay trong file test, thay toàn bộ `jest.fn()` trần bằng `fn()` ở các vị trí chuỗi mock lồng. KHÔNG sửa bất kỳ file production nào để "làm test pass" (đúng yêu cầu BƯỚC 4).
- Sau fix: 0 lỗi, toàn bộ test PASS thật (không skip/không mock giả kết quả).
