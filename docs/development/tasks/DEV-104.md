# DEV-104 — BR-18: `/api-docs` (Swagger UI) mặc định tắt

**Ngày:** 2026-09-30
**Trạng thái:** DONE
**Loại:** SECURITY, CONFIGURATION

**Nguồn:** `docs/31_BACKEND_CODE_REVIEW.md` BR-18 (LOW); cùng gốc với RV00-03 (`docs/module-reviews/00_FOUNDATION_CODE_REVIEW.md`).

## 1. Hiện trạng trước khi sửa

`app.ts` gọi `setupSwagger(app)` vô điều kiện, nên `/api-docs` được phục vụ ở **mọi môi trường**, kể cả production. Trang cho xem toàn bộ API (≈160KB `openAPI.yaml`) và gọi thử ngay trên trình duyệt (`persistAuthorization: true`), không cần đăng nhập để xem.

## 2. Quyết định của user (AskUserQuestion)

- **Mặc định tắt**, chỉ bật khi `NODE_ENV=development` hoặc ENV `ENABLE_API_DOCS=true`.
- Lý do chọn (so với "chỉ tắt khi `NODE_ENV=production`"): quên đặt `NODE_ENV` trên server thì trang vẫn **không** mở ra (fail-closed), cùng kiểu `ALLOW_SELF_REGISTER` (BR-01).
- Không chọn phương án giữ ở production kèm Basic Auth (thêm 1 bộ thông tin đăng nhập phải quản lý).

## 3. Thay đổi

- `config/swagger/swagger.ts`:
  - hàm thuần `isApiDocsEnabled(env)`: `ENABLE_API_DOCS === "true"` (đúng chuỗi này) hoặc `NODE_ENV === "development"` (đúng chữ thường);
  - `setupSwagger(app)` trả `boolean`. Khi tắt thì **không mount và không nạp file YAML** (khởi động nhẹ hơn).
  - Quyết định lúc khởi động, không đọc ENV mỗi request (khác BR-01): đổi cấu hình cần khởi động lại server.
- `app.ts`: không đổi (vẫn gọi `setupSwagger(app)`).
- `.env.example`: thêm `ENABLE_API_DOCS=` kèm giải thích. `README.md`: ghi chú trang mặc định tắt. `PRODUCTION_DEPLOYMENT_PLAN.md` (Giai đoạn 3): không đặt biến này trên production, kèm lệnh kiểm tra sau deploy (`curl -i .../api-docs/` phải 404). `00_FOUNDATION_CODE_REVIEW.md` RV00-03: ghi chú đã sửa.
- **Không ảnh hưởng luồng dev hiện tại:** `.env` của máy dev đang đặt `NODE_ENV=development`, nên `/api-docs` vẫn chạy như cũ.
- Không có route/permission mới; frontend không đổi; OpenAPI không đổi.

## 4. Test

- Unit mới `config/swagger/__tests__/swagger.test.ts` (17 test):
  - bảng 12 tổ hợp ENV (kể cả `"1"`, `"TRUE"`, `""`, `"false"`, `Development`, thiếu `NODE_ENV`);
  - request HTTP vào app express trần: production → 404; thiếu `NODE_ENV` → 404; development → 200 (trang Swagger); production + `ENABLE_API_DOCS=true` → 200.
- E2E mới `__tests__/e2e/api-docs-toggle.e2e-test.ts` (3 test, **app thật** `app.ts`, không cần DB): production → `/api-docs` 404 (route khác vẫn chạy, `/api/users` → 401); `ENABLE_API_DOCS=true` → 200; `NODE_ENV=development` → 200.
- **Đã kiểm chứng test bắt được lỗi ở cả 2 hướng:** (1) tạm khôi phục hành vi cũ (luôn bật) thì 1 test fail; (2) tạm xoá dòng `setupSwagger(app)` khỏi `app.ts` thì 2 test fail (chiều "bật" chứng minh route thật sự được nối vào app). Đã khôi phục cả hai file.
- Backend: `tsc` 0 lỗi, unit 51 suites / 537 tests, e2e 23 suites / 140 tests, `npm run build` PASS. Playwright 16/16 (frontend không đổi code nên không chạy build frontend).

## 5. Ghi chú vận hành

- Muốn xem tài liệu API trên máy chủ thử nghiệm: đặt `ENABLE_API_DOCS=true` rồi khởi động lại.
- Trang không bị bảo vệ bằng đăng nhập khi đã bật: đừng bật trên production thật.
