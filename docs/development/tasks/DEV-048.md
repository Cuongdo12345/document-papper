## Vì sao cần khung RIÊNG (không dùng chung `jest.config.js`)

- E2E cần MongoDB THẬT (không mock) — `withTransaction()` (dùng xuyên suốt Document/Workflow) **bắt buộc** replica set, không chạy được trên standalone.
- Chậm hơn hẳn unit test (khởi động MongoDB in-memory ~vài giây/file) — không nên trộn vào `npm test` (chạy thường xuyên, cần nhanh).
- → Tách hẳn: file đuôi `.e2e-test.ts` (không phải `.test.ts`), thư mục riêng `src/__tests__/e2e/`, config riêng `jest.e2e.config.js`, script riêng `npm run test:e2e`. `jest.config.js` (unit, `npm test`) KHÔNG đổi, KHÔNG bị ảnh hưởng — verify bằng cách chạy lại unit suite sau khi thêm E2E, vẫn đúng 19 suite/150 test như trước.
