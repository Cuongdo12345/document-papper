### 3.1 Suy ra `modules` từ đường dẫn thư mục — KHÔNG hard-code

`buildModelDomainMap()`: quét `fs.readdirSync(backend/src/models/)` → mỗi thư mục con = 1 domain → quét file
`*.model.(ts|js)` trong từng thư mục → `require()` từng file (an toàn, `require()` idempotent nhờ Node
module cache — không tạo `OverwriteModelError` dù model đã được `app.ts` import từ trước) → tìm export nào
là 1 Mongoose Model thật (`findModelExport`: kiểm tra đặc điểm thật — `typeof === "function"` + có
`.modelName` + có `.schema` — KHÔNG đoán tên biến export). **Phát hiện quan trọng khi build**: 31 file model
dùng LẪN LỘN 2 kiểu export (`export const X = model(...)` VÀ `export default model(...)`, xác nhận qua đọc
trực tiếp source, vd `workflowInstance.model.ts`/`user.model.ts` dùng `export default`) — nếu giả định 1 kiểu
export cố định sẽ bỏ sót một nửa số model.

### 3.2 Trích `relationships` từ schema — 4 dạng khai báo ref đã xác nhận CÓ THẬT trong source

Xác nhận bằng script inspect tạm (đã xoá) đọc trực tiếp `schema.paths` của `User`/`Contract`/
`ConsumableRequest`/`WorkflowInstance`/`Document`:

1. ObjectId đơn: `{type: ObjectId, ref: "X"}` → `path.options.ref`.
2. Mảng shorthand: `{type: [ObjectId], ref: "X"}` (vd `User.extraPermissions`) → ref nằm THẲNG ở
   `path.options.ref` — **KHÔNG** nằm ở `path.caster` như giả định ban đầu (đã verify runtime, sửa lại code
   sau khi thấy sai).
3. Mảng object-literal: `[{type: ObjectId, ref: "X"}]` (vd `Contract.assets`) → ref nằm ở
   `path.embeddedSchemaType.options.ref` — HOÀN TOÀN khác cơ chế #2 dù cùng field kiểu "mảng ObjectId ref"
   về mặt business, chỉ khác cú pháp khai báo. Đây là điểm dễ bỏ sót nhất nếu không verify runtime thật.
4. Subdocument/DocumentArray (`path.schema` tồn tại, vd `WorkflowInstance.steps`, `ConsumableRequest.items`,
   `Document.signedBy`) → đệ quy vào `schema.paths` con, đặt tên field dạng `steps[].approvedBy`.

`getSystemDesignService()` gọi `buildModelDomainMap()` (có side-effect `require()` toàn bộ model file)
**TRƯỚC** khi đọc `mongoose.modelNames()` — thứ tự này bắt buộc để đảm bảo `modelNames()` đầy đủ ngay cả khi
process chưa từng import model nào từ trước (áp dụng cho unit test, xem Mục 5).
