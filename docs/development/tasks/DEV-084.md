## 2. Backend — route MỚI hoàn toàn

- `medicalDeviceDashboard.service.ts::getMedicalDevicesByClassListService(deviceClass, params)` — mirror
  đúng cấu trúc `getCalibrationDueListService` cùng file ($lookup asset+department, `runPaginatedAggregate`).
  Chỉ tính profile có Asset `isActive: true` — khớp đúng số đếm ở `byClass` của
  `getMedicalDeviceDashboardSummaryService` (bấm vào số N phải ra đúng N dòng).
- `dashboard.controller.ts::getMedicalDevicesByClass` — `deviceClass` BẮT BUỘC qua query, thiếu/sai →
  400 (khác `daysAhead`/`daysThreshold` các route khác đều có default).
- Route MỚI: `GET /dashboard/medical-devices/by-class`, dùng LẠI permission `DASHBOARD_READ` (cùng mọi
  route dashboard khác — không tạo permission riêng, vì đây vẫn là "xem dashboard").
- **CLAUDE.md §18** — route mới dù dùng lại permission có sẵn vẫn PHẢI verify HTTP thật: viết E2E MỚI
  `medical-device-by-class.e2e-test.ts` (supertest + MongoDB in-memory), 6 test: không token → 401; role
  `USER` (có `ASSET_VIEW`, KHÔNG có `DASHBOARD_READ`) → 403 thật; thiếu/sai `deviceClass` → 400; ADMIN +
  `deviceClass=B` → 200 đúng 2/2 thiết bị (không lẫn Loại C); phân trang đúng; loại không có thiết bị →
  mảng rỗng.
- OpenAPI: thêm path `/api/dashboard/medical-devices/by-class` đầy đủ params/response/400/401/403.

## 3. Frontend

- **Modal MỚI** `MedicalDevicesByClassModal.tsx` (`AppModal` + `DataTable` + `Pagination`, mirror cấu trúc
  `CalibrationDueWidget`) — cột: Mã tài sản, Tên thiết bị (link sang trang chi tiết Asset), Khoa/Phòng,
  Trạng thái (`AssetStatusBadge`), Số đăng ký lưu hành, Hạn kiểm định kế tiếp.
- **Màu sắc** (yêu cầu #2): `features/dashboard/constants/medicalDeviceClass.constants.ts` —
  `DEVICE_CLASS_CONFIG`, thang màu NGỮ NGHĨA tăng dần theo mức rủi ro (A/B/C/D theo quy định phân loại
  thiết bị y tế, rủi ro tăng dần): A=success (xanh lá), B=info (xanh dương), C=warning (vàng cam),
  D=destructive (đỏ, cùng tông "Đã quá hạn" ở KpiCard cùng widget) — trước đó cả 4 loại dùng chung 1 màu
  xám (`variant="default"`).
- **Hover** (yêu cầu #3): mỗi ô đổi từ `<div>` tĩnh sang `<button>`, cùng class hiệu ứng đã dùng ở ô trạng
  thái Asset (DEV-083): `hover:border-primary/40 hover:bg-accent transition-colors`.
- Bấm ô → mở modal đúng loại đã bấm (component `useState` cục bộ, không cần URL param vì không có
  trang đích để deep-link).
- Gộp `MEDICAL_DEVICE_CLASSES`/label cũ (`AssetSummaryWidget.tsx`'s pattern từ DEV-083 — tách file riêng
  để không lặp lỗi oxlint `only-export-components`).
